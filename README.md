## Section 1 — Command Description
My fancy prompt uses both head and grep as one command
## How to Run
node fancyGrep.js FILENAME PATTERN NUMBER
this looks through the file and finds the specific 2 lines that match
## Commands It Combines
head - puts a limit on displayed lines
grep - looks for the lines that have this pattern
